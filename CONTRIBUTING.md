# Внесок у «Тривогу»

Дякуємо за бажання допомогти.

1. Створіть issue з описом помилки або пропозиції.
2. Зробіть окрему гілку від `main`.
3. Не додавайте ключі, персональні дані, зібрані бінарні файли чи каталоги
   `bin`, `obj`, `dist`, `__pycache__`.
4. Для Windows перевірте `dotnet build Tryvoha.csproj -c Release`.
5. Для Linux перевірте `python3 -m py_compile linux/tryvoha.py` та
   `bash -n linux/install.sh`.
6. У pull request коротко опишіть зміни та спосіб перевірки.

Зміни, що можуть вплинути на безпеку людей, повинні зберігати чітке
попередження: застосунок не замінює офіційні сигнали повітряної тривоги.
