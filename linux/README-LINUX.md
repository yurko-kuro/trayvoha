# Тривога для Linux

Версія застосунку «Тривога» для Ubuntu та Debian. Працює у системному треї поточного користувача.

## Встановлення

Розпакуйте `Tryvoha-linux.zip`, відкрийте термінал у розпакованій папці та виконайте:

```bash
chmod +x install.sh uninstall.sh
./install.sh
```

Інсталятор:

- встановлює застосунок лише для поточного користувача;
- додає «Тривогу» до меню застосунків;
- автоматично вмикає запуск після входу до графічної сесії;
- одразу запускає застосунок, якщо встановлення виконується у графічній сесії;
- не запускає другий екземпляр під час повторного встановлення.

Не запускайте інсталятор через `sudo`.

Якщо бракує системних залежностей, інсталятор покаже готову команду `apt` для їх встановлення. Після встановлення залежностей повторно виконайте `./install.sh`.

Ручний запуск:

```bash
~/.local/bin/tryvoha
```

## Видалення

Спочатку закрийте застосунок через меню значка у треї, потім у папці дистрибутива виконайте:

```bash
./uninstall.sh
```

Користувацькі налаштування під час видалення зберігаються у `~/.config/tryvoha`.

## Дані

Налаштування зберігаються у `~/.config/tryvoha/settings.json`.

Джерело даних: NEPTUN.

Застосунок не замінює офіційні сигнали повітряної тривоги.
