# TrayVoha для Linux

TrayVoha для Ubuntu, Debian і Fedora працює у системному треї поточного користувача.

## Ubuntu та Debian: пакет

```bash
sudo apt install ./trayvoha_1.5.0_all.deb
```

## Fedora: пакет

```bash
sudo dnf install ./trayvoha-1.5.0-1.noarch.rpm
```

Пакетний менеджер автоматично встановить залежності. TrayVoha буде доступний у меню та запускатиметься після входу до графічної сесії.

## Переносне встановлення

Розпакуйте `TrayVoha-Linux.zip`, відкрийте термінал у розпакованій папці та виконайте:

```bash
chmod +x install.sh uninstall.sh
./install.sh
```

Інсталятор:

- встановлює TrayVoha лише для поточного користувача;
- додає TrayVoha до меню застосунків;
- автоматично вмикає запуск після входу до графічної сесії;
- одразу запускає застосунок у графічній сесії;
- не запускає другий екземпляр під час повторного встановлення.

Не запускайте інсталятор через `sudo`.

Якщо бракує системних залежностей, інсталятор покаже готову команду `apt` для їх встановлення. Після встановлення залежностей повторно виконайте `./install.sh`.

Ручний запуск:

```bash
~/.local/bin/trayvoha
```

Видалення пакетної версії:

```bash
# Ubuntu та Debian
sudo apt remove trayvoha

# Fedora
sudo dnf remove trayvoha
```

## Видалення переносної версії

Спочатку закрийте TrayVoha через меню значка у треї, потім у папці дистрибутива виконайте:

```bash
./uninstall.sh
```

Користувацькі налаштування під час видалення зберігаються у `~/.config/trayvoha`.

## Дані та приватність

Налаштування зберігаються у `~/.config/trayvoha/settings.json`.

Джерело даних: NEPTUN. TrayVoha не відкриває сайт джерела, не запускає браузер і не використовує геолокацію.

TrayVoha не замінює офіційні сигнали повітряної тривоги.
