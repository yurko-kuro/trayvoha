# Тривога для Linux

Версія застосунку Тривога для Ubuntu та Debian.

## Встановлення

chmod +x install.sh
./install.sh

Після встановлення:

tryvoha

Якщо команда не знаходиться:

~/.local/bin/tryvoha

Налаштування зберігаються у ~/.config/tryvoha/settings.json.

Джерело даних: NEPTUN.

Застосунок не замінює офіційні сигнали повітряної тривоги.
