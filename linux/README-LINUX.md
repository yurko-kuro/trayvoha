# «Тривога» для Linux

Версія для Linux працює у системному треї так само, як Windows-версія:
відкриває вікно вибору територій у системній темі під час першого запуску,
перевіряє стан кожні 10 секунд, показує сповіщення та робить значок червоним
під час тривоги. У сповіщенні для кожної активної території також зазначається
час оголошення тривоги.

## Встановлення на Ubuntu/Debian

```bash
chmod +x install.sh
./install.sh
tryvoha
```

Якщо не вистачає системних пакетів, інсталятор покаже готову команду
`sudo apt install`. Після встановлення пакетів запустіть `./install.sh` ще раз.

Якщо `~/.local/bin` ще не доданий до `PATH`, запускайте так:

```bash
~/.local/bin/tryvoha
```

Автозапуск вмикається галочкою `Запускати разом із системою` у меню значка.
Налаштування зберігаються у `~/.config/tryvoha/settings.json`. Під час першого
запуску налаштування попередньої версії AlertTray переносяться автоматично.

Дані: [Карта повітряних тривог — NEPTUN](https://neptun.in.ua/).

Застосунок не замінює офіційні сигнали повітряної тривоги.
