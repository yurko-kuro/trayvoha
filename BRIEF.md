# Короткий бриф TrayVoha

## Що це

TrayVoha — невеликий застосунок системного трея для Windows і Linux, який показує стан повітряної тривоги для вибраних користувачем територій України.

Застосунок не намагається визначати місцезнаходження користувача. Області та райони вибираються вручну.

## Як це працює

1. Користувач запускає TrayVoha.
2. Під час першого запуску вибирає одну або кілька областей чи районів.
3. Вибір зберігається локально на пристрої.
4. TrayVoha приблизно раз на 10 секунд отримує актуальний список тривог із NEPTUN.
5. Отримані дані локально зіставляються з вибраними територіями.
6. Значок у системному треї показує поточний стан, а при зміні стану застосунок показує системне сповіщення.

Схема роботи:

`Користувач → вибір територій → TrayVoha → HTTPS → NEPTUN → локальна перевірка → значок і сповіщення`

## Джерело даних

Єдиний зовнішній runtime endpoint:

`https://neptun.in.ua/api/v1/alerts`

TrayVoha отримує загальний список активних тривог. Вибрані користувачем області або райони не передаються NEPTUN як параметри запиту — фільтрація виконується локально.

HTTP redirects заборонені. Розмір відповіді обмежений до 1 MiB.

## Що бачить користувач

У треї застосунок показує один із базових станів:

- тривоги немає;
- повітряна тривога активна;
- дані тимчасово недоступні або стан ще перевіряється.

Через меню можна:

- змінити список територій;
- вручну перевірити стан;
- увімкнути або вимкнути автозапуск;
- вийти із застосунку.

## Windows

Windows-версія постачається як self-contained `TrayVoha.exe`, тому окремо встановлювати .NET Runtime не потрібно.

Також передбачений звичайний installer `TrayVoha-Setup-x64.exe`, який встановлює застосунок у Program Files, створює запис для видалення та ярлик у меню Пуск.

Автозапуск не вмикається самим installer-ом — користувач керує ним окремо з меню TrayVoha.

## Linux

Linux-версія працює як GTK/AppIndicator-застосунок системного трея.

Передбачені Debian- та RPM-пакування, а також користувацький install-скрипт. Налаштування і вибрані території зберігаються в локальному профілі користувача.

## Приватність і безпека

TrayVoha не використовує:

- GPS або системні Location API;
- IP-geolocation;
- Wi-Fi/Bluetooth positioning;
- браузер для визначення місцезнаходження;
- телеметрію;
- акаунти, паролі або API-токени;
- завантаження та виконання стороннього коду.

Runtime-мережа обмежена HTTPS-з'єднанням із NEPTUN на порт 443. На Windows це додатково перевіряється live runtime-аудитом у CI.

## Локальні дані

Windows:

`%APPDATA%\TrayVoha\settings.json`

Linux:

`~/.config/trayvoha/settings.json`

У цих файлах зберігаються тільки локальні налаштування застосунку, зокрема вибрані території.

## Для чого TrayVoha

Основна ідея — дати простий фоновий індикатор тривоги без відкритої вкладки браузера, зайвого інтерфейсу або постійної ручної перевірки.

TrayVoha є допоміжним засобом і не замінює офіційні канали оповіщення про повітряну тривогу.
