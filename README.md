# Тривога

[![CI](https://github.com/yurko-kuro/tryvoha-desktop/actions/workflows/ci.yml/badge.svg)](https://github.com/yurko-kuro/tryvoha-desktop/actions/workflows/ci.yml)

**Повітряні тривоги для вибраних районів та областей України у системному треї Windows і Linux.**

## Завантаження

Поточна стабільна версія: **v1.4.3**.

Готова збірка публікується одним файлом у [Releases](https://github.com/yurko-kuro/tryvoha-desktop/releases):

**`Тривога.zip`**

Усередині архіву:

```text
Тривога.zip
├── Windows/
│   ├── Тривога.exe
│   └── файли середовища та бібліотеки
├── Linux/
└── README.md
```

Гілка `main` містить актуальний вихідний код. Для звичайного використання завантажуйте готовий `Тривога.zip` зі сторінки Releases.

## Можливості

- вибір окремих районів або цілої області;
- одночасне відстеження територій із різних областей;
- сповіщення про початок тривоги, зміну активних територій та відбій;
- показ часу оголошення тривоги для кожної активної території;
- компактна картка поточного стану;
- червоний значок під час активної тривоги;
- світла та темна тема;
- автозапуск разом із системою;
- локальне збереження налаштувань;
- без реєстрації, реклами та аналітики.

Для сьогоднішньої тривоги час показується у форматі `19:42`, для попередньої дати — `31.08, 23:42`.

> **Важливо:** «Тривога» є допоміжним інформаційним застосунком і не замінює офіційні сигнали повітряної тривоги. Завжди дотримуйтеся вказівок офіційних органів та прямуйте в укриття за сигналом тривоги.

## Windows

1. Завантажте `Тривога.zip` зі сторінки Releases.
2. Розпакуйте архів у постійний каталог.
3. Відкрийте папку `Windows`.
4. Запустіть `Тривога.exe`.

Встановлювати Python або .NET окремо не потрібно. Windows-збірка містить необхідне середовище виконання та бібліотеки.

Не переносіть `Тривога.exe` окремо від інших файлів папки `Windows`: вони є частиною portable-збірки.

Автозапуск можна ввімкнути в меню значка у системному треї.

## Linux

Для Ubuntu/Debian відкрийте термінал у папці `Linux` і виконайте:

```bash
chmod +x install.sh
./install.sh
tryvoha
```

Якщо бракує системних пакетів, інсталятор покаже готову команду `sudo apt install`. Після встановлення залежностей запустіть `./install.sh` ще раз.

Якщо `~/.local/bin` не доданий до `PATH`, запускайте:

```bash
~/.local/bin/tryvoha
```

Докладніша інструкція міститься у `Linux/README-LINUX.md`.

## Збірка з вихідного коду

### Windows

Потрібні Windows 10/11 та .NET 8 SDK.

```powershell
.\build-windows.ps1
```

Результат буде у каталозі:

```text
dist\windows\
```

### Linux

Linux-версія не потребує окремої компіляції. Вихідні файли знаходяться у каталозі `linux/`.

## Дані

Дані про тривоги надає [NEPTUN](https://neptun.in.ua/) через відкритий API. Дані можуть надходити із затримкою або містити неточності.
