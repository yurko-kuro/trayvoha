# Тривога

Невеликий застосунок для Windows і Linux, який працює у системному треї та показує стан повітряних тривог для вибраних районів і областей України.

## Можливості

- вибір окремих районів або цілої області;
- одночасне відстеження кількох територій;
- сповіщення про початок та відбій повітряної тривоги;
- показ часу оголошення тривоги;
- червоний значок у треї під час активної тривоги;
- світла та темна тема;
- автоматичний запуск після входу до системи;
- Windows 10/11, Ubuntu/Debian і Fedora;
- без реєстрації, реклами та API-ключів.

## Завантаження

Перевірені збірки знаходяться у розділі [Releases](https://github.com/yurko-kuro/tryvoha-desktop/releases).

Для кожної системи опубліковано окремий файл:

- `Tryvoha-Desktop-Windows.zip` — переносна Windows-версія;
- `Tryvoha-Desktop-Linux.zip` — переносна Linux-версія;
- `tryvoha-desktop_*_all.deb` — пакет для Ubuntu/Debian;
- `tryvoha-desktop-*.noarch.rpm` — пакет для Fedora.

## Windows

Завантажте та розпакуйте `Tryvoha-Windows.zip`, потім запустіть `Тривога.exe`.

Windows-версія містить автономний комплект усіх потрібних файлів і не потребує окремого встановлення .NET.

## Linux

Для Ubuntu та Debian завантажте `.deb` і виконайте:

```bash
sudo apt install ./tryvoha_1.4.0_all.deb
```

Для Fedora завантажте `.rpm` і виконайте:

```bash
sudo dnf install ./tryvoha-1.4.0-1.noarch.rpm
```

Пакети встановлюють залежності, додають застосунок до меню та вмикають автозапуск після входу до графічної сесії.

Для переносного встановлення завантажте і розпакуйте `Tryvoha-Linux.zip`, відкрийте термінал у розпакованій папці та виконайте:

```bash
chmod +x install.sh uninstall.sh
./install.sh
```

Скрипт встановить застосунок для поточного користувача, одразу запустить його у графічній сесії та додасть до автозапуску. Запускати скрипт через `sudo` не потрібно.

Докладні інструкції наведено у файлі `README-LINUX.md`.

## Дані та приватність

Джерело даних: [NEPTUN](https://neptun.in.ua/).

Налаштування зберігаються лише локально. Застосунок не потребує облікового запису та не передає користувацькі дані на власний сервер.

## Важливо

«Тривога» є допоміжним інформаційним застосунком і не замінює офіційні сигнали повітряної тривоги.
