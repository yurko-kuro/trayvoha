# AlertTray

Невелика програма без постійного основного вікна для Windows і Linux. Працює у
системному треї, перевіряє поточні повітряні тривоги та показує системне
сповіщення, коли стан на вибраних територіях змінюється.

Після першого запуску території не вибрані: користувач сам ставить галочки біля
потрібних районів або цілих регіонів.

## Що вміє

- показує поточний стан одразу після запуску;
- опитує API раз на 10 секунд;
- повідомляє про зміну переліку районів із тривогою та про відбій;
- дозволяє одночасно вибрати кілька районів із різних областей;
- підлаштовує світлу або темну тему під налаштування системи;
- підтримує вибір усього регіону замість окремих районів;
- показує всі вибрані території окремими рядками у сповіщенні;
- показує час оголошення активної тривоги для кожної території;
- змінює значок у треї на червоний, коли є тривога;
- лівим кліком відкриває власне вікно стану біля трея, навіть коли системні сповіщення вимкнені;
- може запускатися разом із Windows;
- не потребує API-ключа.

## Збірка EXE

Потрібні Windows 10/11 і [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

Відкрийте PowerShell у каталозі проєкту та виконайте:

```powershell
.\build-windows.ps1
```

Готовий автономний файл буде тут:

```text
dist\AlertTray.exe
```

Встановлення не потрібне. Перемістіть EXE у постійний каталог, запустіть його,
а потім за потреби ввімкніть пункт `Запускати разом із Windows` у меню трея.

## Linux

Для Ubuntu/Debian відкрийте термінал у каталозі проєкту та виконайте:

```bash
chmod +x linux/install.sh
./linux/install.sh
alerttray
```

Якщо команда `alerttray` ще не знаходиться, запустіть:

```bash
~/.local/bin/alerttray
```
