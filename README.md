# Тривога

Невеликий застосунок для Windows і Linux, який працює у системному треї та показує стан повітряних тривог для вибраних районів і областей України.

## Можливості

- вибір окремих районів або цілої області;
- одночасне відстеження кількох територій;
- сповіщення про початок та відбій повітряної тривоги;
- показ часу оголошення тривоги;
- червоний значок у треї під час активної тривоги;
- світла та темна тема;
- автозапуск;
- Windows 10/11 та Ubuntu/Debian;
- без реєстрації, реклами та API-ключів.

## Завантаження

Готовий архів знаходиться у розділі Releases.

Файл: Tryvoha.zip

## Windows

Розпакуйте архів, відкрийте папку Windows і запустіть Тривога.exe.

Поруч із програмою знаходяться 5 службових DLL-файлів. Не видаляйте їх.

Windows-версія автономна та не потребує окремого встановлення .NET.

## Linux

У папці Linux виконайте:

chmod +x install.sh
./install.sh
tryvoha

## Дані

Джерело даних: https://neptun.in.ua/

Налаштування зберігаються локально.

## Важливо

Тривога є допоміжним інформаційним застосунком і не замінює офіційні сигнали повітряної тривоги.
