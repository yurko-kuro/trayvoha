# Тривога · Tryvoha

[![CI](https://github.com/yurko-kuro/tryvoha-desktop/actions/workflows/ci.yml/badge.svg)](https://github.com/yurko-kuro/tryvoha-desktop/actions/workflows/ci.yml)

**Повітряні тривоги для вибраних районів та областей України — просто у системному треї.**

«Тривога» — невеликий застосунок без постійного основного вікна для Windows і Linux. Він перевіряє стан вибраних територій, повідомляє про початок та відбій тривоги й показує поточний стан одним кліком.

> **Важливо:** «Тривога» є допоміжним інформаційним інструментом. Вона не замінює офіційні сигнали повітряної тривоги. Завжди дотримуйтеся вказівок офіційних органів та прямуйте в укриття за сигналом тривоги.

## Можливості

- окремий вибір районів або цілої області;
- одночасне відстеження територій із різних областей;
- сповіщення про початок тривоги, зміну активних територій та відбій;
- час оголошення тривоги для кожної активної території;
- компактна картка стану біля трея;
- червоний значок під час активної тривоги;
- світла і темна тема;
- автозапуск разом із системою;
- Windows 10/11 та Ubuntu/Debian;
- без реєстрації, реклами, аналітики та API-ключів.

Усі налаштування зберігаються локально. Застосунок виконує лише GET-запити до відкритого API джерела даних.

Під час активної тривоги картка стану та системне сповіщення показують час її оголошення. Для сьогоднішньої події використовується формат `19:42`, для давнішої — `31.08, 23:42`. Якщо вибрано цілу область, застосунок показує кожен активний район окремо; загальна обласна тривога відображається одним рядком із найранішим часом початку.

## Завантаження

Готові версії публікуються на сторінці [Releases](https://github.com/yurko-kuro/tryvoha-desktop/releases).

Починаючи з версії **1.4.2**, основний релізний файл — один portable-архів:

`Tryvoha-v1.4.2-portable.zip`

Усередині:

```text
Tryvoha-v1.4.2-portable.zip
├── Windows/
├── Linux/
└── README.md
```

## Windows

1. Завантажте portable-архів зі сторінки Releases.
2. Розпакуйте архів у будь-який постійний каталог.
3. Відкрийте папку `Windows`.
4. Запустіть `Tryvoha.exe`.

Встановлювати .NET або Python не потрібно: Windows-версія вже містить потрібний .NET runtime та залежності.

**Не переносіть лише `Tryvoha.exe` окремо від інших файлів папки `Windows`.** Це папочна portable-збірка, тому всі файли поруч із програмою є частиною застосунку.

Автозапуск можна ввімкнути в меню значка в системному треї.

## Linux

Для Ubuntu/Debian відкрийте термінал у папці `Linux` і виконайте:

```bash
chmod +x install.sh
./install.sh
tryvoha
```

Якщо не вистачає системних пакетів, інсталятор покаже готову команду `sudo apt install`. Після встановлення пакетів запустіть `./install.sh` ще раз.

Якщо `~/.local/bin` ще не доданий до `PATH`, запускайте так:

```bash
~/.local/bin/tryvoha
```

Докладніше: `Linux/README-LINUX.md`.

## Оновлення зі старого AlertTray

Windows- і Linux-версії автоматично переносять вибрані території зі старого каталогу налаштувань. Старий запис автозапуску також замінюється новим.

## Збірка з вихідного коду

### Windows

Потрібні Windows 10/11 і [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```powershell
.\build-windows.ps1
```

Готова папочна автономна збірка буде у:

```text
dist\windows\
```

Для її запуску на іншому Windows-комп'ютері встановлення .NET не потрібне.

### Linux

Linux-версія не потребує окремої компіляції. Вихідні файли знаходяться у каталозі `linux/`.

## Дані та атрибуція

Дані про тривоги надає [NEPTUN](https://neptun.in.ua/) через [відкритий API](https://neptun.in.ua/developers). API може містити затримки або неточності та надається без гарантій.
