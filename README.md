# Тривога · Tryvoha

[![CI](https://github.com/yurko-kuro/tryvoha-desktop/actions/workflows/ci.yml/badge.svg)](https://github.com/yurko-kuro/tryvoha-desktop/actions/workflows/ci.yml)

**Повітряні тривоги для вибраних районів та областей України — просто у системному треї.**

«Тривога» — невеликий застосунок без постійного основного вікна для Windows і
Linux. Він перевіряє стан вибраних територій, повідомляє про початок та відбій
тривоги й показує поточний стан одним кліком.

> **Важливо:** «Тривога» є допоміжним інформаційним інструментом. Вона не
> замінює офіційні сигнали повітряної тривоги. Завжди дотримуйтеся вказівок
> офіційних органів та прямуйте в укриття за сигналом тривоги.

## Можливості

- окремий вибір районів або цілої області;
- одночасне відстеження територій із різних областей;
- сповіщення про початок тривоги, зміну активних територій та відбій;
- час оголошення тривоги для кожної активної території;
- власна компактна картка стану біля трея;
- червоний значок під час активної тривоги;
- світла і темна тема;
- автозапуск разом із системою;
- Windows 10/11 та Ubuntu/Debian;
- без реєстрації, реклами, аналітики та API-ключів.

Усі налаштування зберігаються локально. Застосунок виконує лише GET-запити до
відкритого API джерела даних.

Під час активної тривоги картка стану та системне сповіщення показують час її
оголошення. Для сьогоднішньої події використовується формат `19:42`, для
давнішої — `31.08, 23:42`. Якщо вибрано цілу область, застосунок показує кожен
активний район окремо; загальна обласна тривога відображається одним рядком із
найранішим часом початку.

## Windows

Завантажте `Tryvoha.exe` зі сторінки
[Releases](https://github.com/yurko-kuro/tryvoha-desktop/releases). Встановлення
не потрібне: перемістіть файл у постійний каталог і запустіть. Автозапуск можна
ввімкнути в меню значка.

### Збірка з вихідного коду

Потрібні Windows 10/11 і [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```powershell
.\build-windows.ps1
```

Готовий автономний файл: `dist\Tryvoha.exe`.

## Linux

Для Ubuntu/Debian:

```bash
chmod +x linux/install.sh
./linux/install.sh
tryvoha
```

Якщо `~/.local/bin` ще не доданий до `PATH`, запустіть:

```bash
~/.local/bin/tryvoha
```

Докладніше: [інструкція для Linux](linux/README-LINUX.md).

## Оновлення з AlertTray

Windows- і Linux-версії автоматично переносять вибрані території зі старого
каталогу налаштувань. Старий запис автозапуску також замінюється новим.

## Дані та атрибуція

Дані про тривоги надає [NEPTUN](https://neptun.in.ua/) через
[відкритий API](https://neptun.in.ua/developers). API може містити затримки або
неточності та надається без гарантій.
