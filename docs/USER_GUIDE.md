# Інструкція користувача TrayVoha

## Перший запуск

Після першого запуску TrayVoha запропонує вибрати території, за якими потрібно стежити.

Можна вибрати:

- одну або кілька областей;
- окремі райони;
- область цілком замість її окремих районів.

Після натискання `Зберегти` вибір записується локально на цьому комп'ютері. Геолокація для вибору території не використовується.

## Що означає значок

TrayVoha постійно працює у системному треї або menu bar.

Основні стани:

- звичайний значок — на вибраних територіях активної повітряної тривоги немає;
- червоний значок — на одній або кількох вибраних територіях активна повітряна тривога;
- помаранчевий значок із `!` — дані ще перевіряються або джерело тимчасово недоступне.

При зміні стану TrayVoha показує системне сповіщення.

## Windows

TrayVoha знаходиться в області сповіщень біля годинника.

- **Подвійний лівий клік по значку** — перевірити та показати поточний стан вибраних територій.
- **Правий клік по значку** — відкрити меню TrayVoha.

У меню доступні:

- `Налаштувати території…` — змінити області та райони;
- `Показати стан зараз` — вручну оновити й показати поточний стан;
- `Запускати разом із Windows` — увімкнути або вимкнути автозапуск;
- `Вийти` — повністю закрити TrayVoha.

## Linux

TrayVoha працює через системний AppIndicator/системний трей.

Клацніть значок TrayVoha, щоб відкрити меню. Далі можна вибрати:

- `Налаштувати території…`;
- `Показати стан зараз`;
- `Запускати разом із системою`;
- `Вийти`.

Точна кнопка миші, якою середовище робочого столу відкриває AppIndicator-меню, може залежати від GNOME/KDE та реалізації системного трея.

## macOS

TrayVoha знаходиться у menu bar у верхній частині екрана.

Клацніть значок TrayVoha, щоб відкрити меню. У ньому доступні:

- `Налаштувати території…` — вибір областей та районів;
- `Показати стан зараз` — ручна перевірка;
- `Запускати разом із macOS` — керування автозапуском;
- `Вийти` — закриття застосунку.

Інтерфейс автоматично використовує поточну Light/Dark тему macOS.

## Як змінити території

Відкрийте меню TrayVoha та виберіть `Налаштувати території…`.

Правила вибору:

- галочка на області означає відстеження всієї області;
- якщо потрібні лише окремі райони, вибирайте райони замість області;
- можна одночасно відстежувати території з різних областей;
- `Зняти всі` очищує поточний вибір;
- зміни набувають чинності після `Зберегти`.

Після зміни територій TrayVoha одразу виконує нову перевірку.

## Як вручну перевірити стан

Відкрийте меню та виберіть `Показати стан зараз`.

TrayVoha виконає запит до джерела даних та покаже актуальний результат для вибраних територій.

Звичайна автоматична перевірка відбувається приблизно раз на 10 секунд, тому постійно натискати цю команду не потрібно.

## Автозапуск

Автозапуск не є обов'язковим.

Якщо ввімкнути відповідний пункт меню, TrayVoha запускатиметься після входу користувача до операційної системи.

Windows installer самостійно автозапуск не вмикає.

## Системна тема

TrayVoha використовує тему операційної системи:

- Windows — системну Light/Dark тему застосунків;
- Linux — поточну GTK-тему середовища;
- macOS — системний Light/Dark appearance.

## Якщо показано «дані недоступні»

Це означає, що TrayVoha не зміг отримати коректну відповідь від джерела даних.

Перевірте підключення до Інтернету. Додаткових дій зазвичай не потрібно — TrayVoha продовжить автоматичні перевірки.

Стан `дані недоступні` не слід трактувати як відсутність повітряної тривоги.

## Важливо

TrayVoha є допоміжним інформаційним застосунком. Для рішень, пов'язаних із безпекою, орієнтуйтеся насамперед на офіційні сигнали повітряної тривоги та вказівки органів влади.
