# Короткий бриф TrayVoha

## Що це

TrayVoha — невеликий фоновий застосунок для Windows, Linux і macOS, який показує стан повітряної тривоги для вибраних користувачем територій України.

Місцезнаходження користувача не визначається: області та райони вибираються вручну.

## Як це працює

1. Користувач запускає TrayVoha.
2. Під час першого запуску вибирає одну або кілька областей чи районів.
3. Вибір зберігається локально на пристрої.
4. TrayVoha приблизно раз на 10 секунд отримує актуальний список тривог із NEPTUN.
5. Отримані дані локально зіставляються з вибраними територіями.
6. Значок у треї або menu bar показує поточний стан, а при зміні стану застосунок показує системне сповіщення.

`Користувач → вибір територій → TrayVoha → HTTPS → NEPTUN → локальна перевірка → значок і сповіщення`

## Джерело даних

Єдиний зовнішній runtime endpoint:

`https://neptun.in.ua/api/v1/alerts`

TrayVoha отримує загальний список активних тривог. Вибрані області або райони не передаються NEPTUN як параметри запиту — фільтрація виконується локально.

HTTP redirects заборонені. Розмір відповіді обмежений до 1 MiB.

Детальніше: [NEPTUN як джерело даних](NEPTUN.md).

## Що бачить користувач

Основні стани:

- тривоги немає;
- повітряна тривога активна;
- дані тимчасово недоступні або стан ще перевіряється.

Через меню можна змінити території, вручну перевірити стан, керувати автозапуском і вийти із застосунку.

## Платформи

### Windows

Self-contained `TrayVoha.exe` і звичайний installer. Окремий .NET Runtime не потрібен. Тема визначається системною Light/Dark темою Windows.

### Linux

GTK/AppIndicator-застосунок із Debian/RPM-пакуванням і переносним install-скриптом. Інтерфейс успадковує системну GTK-тему.

### macOS

Нативний Swift/AppKit menu-bar застосунок. Використовує системні Light/Dark appearance, Notification Center та штатний механізм автозапуску macOS.

## Приватність і безпека

TrayVoha не використовує:

- GPS або системні Location API;
- IP-geolocation;
- Wi-Fi/Bluetooth positioning;
- браузер для визначення місцезнаходження;
- телеметрію;
- акаунти, паролі або API-токени;
- завантаження та виконання стороннього коду.

Вибір територій зберігається локально. Runtime-мережа обмежена HTTPS-з'єднанням із NEPTUN.

## Для чого TrayVoha

Основна ідея — дати простий фоновий індикатор тривоги без відкритої вкладки браузера, зайвого інтерфейсу або постійної ручної перевірки.

TrayVoha є допоміжним засобом і не замінює офіційні канали оповіщення про повітряну тривогу.
