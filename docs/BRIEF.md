# Короткий бриф TrayVoha

## Що це

TrayVoha — фоновий застосунок для Windows, Linux і macOS, який показує стан повітряної тривоги для вибраних користувачем територій України.

Місцезнаходження користувача не визначається: області та райони вибираються вручну.

## Як це працює

1. Користувач запускає TrayVoha.
2. Вибирає одну або кілька областей чи районів.
3. Вибір зберігається локально.
4. Приблизно раз на 10 секунд TrayVoha отримує список активних тривог із NEPTUN.
5. Дані локально зіставляються з вибраними територіями.
6. Значок у tray/menu bar показує стан, а зміни супроводжуються системним сповіщенням.

`Користувач → вибір територій → TrayVoha → HTTPS → NEPTUN → локальна перевірка → значок і сповіщення`

## Джерело даних

Єдиний зовнішній runtime endpoint:

`https://neptun.in.ua/api/v1/alerts`

Вибрані області та райони не передаються NEPTUN як параметри запиту. HTTP redirects заборонені. Розмір відповіді обмежений до 1 MiB.

Детальніше: [NEPTUN як джерело даних](NEPTUN.md).

## Платформи

### Windows

C# / .NET 8 / Windows Forms. Self-contained `TrayVoha.exe`, portable ZIP та installer. Автозапуск — через HKCU Run.

### Linux

Python 3 / GTK 3 / PyGObject / AppIndicator. Пакування: `.deb`, `.rpm` та portable ZIP. Автозапуск — через XDG Autostart.

### macOS

Swift / AppKit / Foundation. Universal `TrayVoha.app` для `arm64` і `x86_64`, ZIP та DMG. Сповіщення — через UserNotifications, автозапуск — через `SMAppService`.

Повний технічний склад: [Технічна реалізація](TECHNICAL.md).

## Дані та приватність

TrayVoha не використовує:

- GPS або системні Location API;
- IP-geolocation;
- Wi-Fi/Bluetooth positioning;
- browser-mediated geolocation;
- телеметрію;
- акаунти, паролі або API-токени;
- завантаження та виконання стороннього коду.

Вибір територій зберігається локально. Runtime-мережа обмежена HTTPS-з'єднанням із NEPTUN.

## Призначення

TrayVoha дає постійний фоновий індикатор стану без відкритої вкладки браузера та ручної перевірки.

TrayVoha є допоміжним засобом і не замінює офіційні канали оповіщення про повітряну тривогу.
