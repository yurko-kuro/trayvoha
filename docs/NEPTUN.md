# NEPTUN як джерело даних TrayVoha

Цей документ пояснює, що саме TrayVoha отримує від NEPTUN, звідки походять ці дані та які обмеження довіри має джерело.

Актуальність перевірена: **3 вересня 2026 року**.

## Що таке NEPTUN

NEPTUN (`https://neptun.in.ua/`) — український інформаційний агрегатор повітряних тривог і повітряних загроз. Сам NEPTUN прямо зазначає, що не є офіційною системою оповіщення цивільного захисту та не замінює державні канали повітряної тривоги.

TrayVoha не використовує карту загроз, Telegram-стрічки, прогнозовані траєкторії БпЛА або інші аналітичні дані NEPTUN.

## Що саме використовує TrayVoha

Єдиний endpoint:

`GET https://neptun.in.ua/api/v1/alerts`

Документація NEPTUN описує його як endpoint офіційних статусів повітряної тривоги для районів та областей.

Типова відповідь містить два набори:

- `raions` — активні тривоги на рівні районів;
- `oblasts` — активні тривоги на рівні областей або територій, для яких статус подається цілим регіоном.

TrayVoha отримує загальний snapshot, після чого **локально** зіставляє його з територіями, які вибрав користувач. Вибрані райони та області не надсилаються NEPTUN як параметри запиту.

## Звідки NEPTUN бере статус тривоги

NEPTUN окремо пояснює, що статус повітряної тривоги не формується з Telegram-повідомлень.

Для статусу тривог NEPTUN використовує **UkraineAlarm / офіційний API повітряних тривог**. На сторінці джерел NEPTUN цей API позначено як єдине джерело статусу повітряної тривоги на рівні районів.

Інші джерела NEPTUN — Повітряні Сили, ОВА, моніторингові та агрегаторні Telegram-канали — використовуються для інформації про тип і рух загроз, але **TrayVoha ці дані не запитує**.

Публічні сторінки NEPTUN:

- https://neptun.in.ua/developers
- https://neptun.in.ua/
- https://neptun.in.ua/faq
- https://neptun.in.ua/api-terms

## Наскільки джерело актуальне

Станом на дату перевірки:

- NEPTUN активно працює та публікує API для розробників;
- документація `GET /api/v1/alerts` доступна;
- реєстр джерел NEPTUN вказує, що офіційний статус тривоги береться окремо з UkraineAlarm API;
- умови API були оновлені 9 липня 2026 року;
- сторінка джерел NEPTUN повідомляє про оновлення реєстру 1 серпня 2026 року;
- Windows runtime-аудит TrayVoha в CI фактично встановлює HTTPS-з'єднання з `neptun.in.ua` та отримує дані під час перевірки.

Це є хорошими ознаками поточної працездатності джерела, але **не є гарантією майбутньої доступності або безпомилковості**.

## Наскільки це безпечно для TrayVoha

З точки зору мережевої поверхні TrayVoha навмисно обмежує довіру до джерела:

- використовується лише HTTPS;
- endpoint жорстко зафіксований у runtime;
- HTTP redirects заборонені;
- максимальний розмір response body — 1 MiB;
- відповідь обробляється лише як JSON-дані;
- отриманий вміст не виконується як код;
- застосунок не відкриває браузер або URL із відповіді;
- вибір територій не передається у request body або query string.

Таким чином, компрометація або помилка NEPTUN насамперед створює ризик **цілісності та доступності даних**: TrayVoha може показати неправильний, застарілий або відсутній статус. Це не повинно перетворюватися на штатний механізм віддаленого виконання коду.

## Що бачить NEPTUN

Як і будь-який HTTPS-сервер, NEPTUN може бачити звичайні мережеві метадані запиту, зокрема:

- публічну IP-адресу підключення;
- час і частоту запитів;
- TLS/HTTP metadata;
- User-Agent TrayVoha.

NEPTUN не отримує від TrayVoha список вибраних користувачем районів або областей.

## Частота запитів

TrayVoha перевіряє стан приблизно раз на 10 секунд.

Умови NEPTUN дозволяють опитування REST snapshot не частіше одного разу на 5 секунд, тому поточний інтервал TrayVoha знаходиться в межах заявленого правила навантаження.

## Атрибуція

Умови API NEPTUN вимагають видиму атрибуцію з посиланням на `https://neptun.in.ua/` поруч із даними.

TrayVoha вже показує текст `Джерело: NEPTUN`, але перед публічним релізом потрібно окремо підтвердити відповідність формату атрибуції умовам NEPTUN. Якщо потрібне буквальне посилання, його слід показувати як видимий URL/атрибуцію без автоматичного відкриття браузера.

Цей пункт не слід вважати закритим лише на підставі наявного тексту `Джерело: NEPTUN`.

## Обмеження довіри

NEPTUN у власних умовах прямо зазначає:

- сервіс є інформаційним агрегатором;
- API надається «як є»;
- точність, повнота та доступність не гарантуються;
- endpoint може змінюватися або припинити роботу;
- сервіс не є заміною офіційної системи оповіщення.

Тому TrayVoha також повинен чітко залишатися **допоміжним індикатором**, а не єдиним каналом отримання критичних повідомлень.

## Підсумок

Для задачі TrayVoha NEPTUN зараз є практичним проміжним API: він віддає простий районний/обласний snapshot, а сам статус тривоги, за документацією NEPTUN, походить з офіційного UkraineAlarm API.

При цьому межа довіри залишається чіткою: TrayVoha довіряє NEPTUN лише як транспортному джерелу статусу, технічно обмежує мережеву взаємодію і не заявляє, що NEPTUN є офіційною системою оповіщення.
