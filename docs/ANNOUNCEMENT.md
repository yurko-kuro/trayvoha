TrayVoha — локальний клієнт сповіщення про повітряні тривоги

TrayVoha — кросплатформний застосунок для оперативного відображення актуального стану повітряної тривоги через сповіщення в системному треї робочого пристрою користувача.

Основні можливості:

- Робота у фоновому режимі
- Вибір області та необхідних районів
- Отримання актуальних даних про повітряні тривоги через API системи Neptune
- Сповіщення про початок та завершення повітряної тривоги
- Підтримка Windows, Linux та macOS

Контур безпеки:

- Лише вихідні HTTPS-запити до API Neptune
- Вхідні мережеві з’єднання не використовуються
- Доступ до корпоративних інформаційних систем не потрібен
- Реєстрація та обліковий запис не потрібні
- Геолокація не запитується та не використовується
- Персональні дані не збираються та не передаються
- Телеметрія відсутня
- Дані про тривоги обробляються локально та використовуються лише для відображення стану й формування сповіщень
